# Student Grade Calculator

## Description

Student Grade Calculator is a simple Python desktop application that calculates a student's total marks, percentage, and grade based on the marks entered for different subjects.

## Features

- Enter student name
- Enter marks for multiple subjects
- Calculate total marks
- Calculate percentage
- Display the student's grade
- Validate marks between 0 and 100
- Simple and user-friendly graphical interface

## Grade System

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A+    |
| 80 - 89    | A     |
| 70 - 79    | B     |
| 60 - 69    | C     |
| 50 - 59    | D     |
| Below 50   | F     |

## Technology Used

- Python
- Tkinter
